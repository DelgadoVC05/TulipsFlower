# 🌷 Beautiful Tulips - A Romantic Gift

A beautiful, animated tulip garden with day/night modes, created with love to share with someone special.

## ✨ Features

### 🌸 Three Beautiful Tulips

- **Center Tulip** (Pink) - The main flower, elegant and graceful
- **Left Tulip** (Purple) - A smaller companion in lovely lavender tones
- **Right Tulip** (Pink) - Another beautiful bloom completing the bouquet

### 🎨 Visual Enhancements

- **Smooth Animations**: Natural swaying motion simulating gentle breeze
- **Sparkling Details**: Each tulip has a delicate sparkle instead of eyes
- **Glowing Blush**: Soft, pulsing pink blush for a romantic touch
- **Gradient Colors**: Rich, multi-layered color gradients on petals and leaves
- **Dynamic Shadows**: Realistic drop shadows that change with lighting

### 🌅 Day/Night Mode

Switch between two beautiful scenes:

#### ☀️ Morning Mode

- Bright blue sky with golden sunrise gradient
- Glowing sun with radiant halo effect
- Light green grass and ground
- Perfect for daytime viewing

#### 🌙 Evening Mode

- Deep twilight sky with gradient blues
- Glowing moon with realistic craters
- 150+ twinkling stars
- Darker, mysterious ground tones
- Enhanced glow effects on tulips

### 💕 Romantic Elements

- **Heartfelt Message**: "For Someone Special" displayed at the top
- **Floating Hearts**: Hearts continuously float upward
- **Butterflies**: Two animated butterflies fly around the scene
- **Elegant Typography**: Classic serif fonts for a timeless feel


### Interacting with the Scene

- **Click the Button** in the top-left corner to toggle between Morning ☀️ and Evening 🌙 modes
- **Watch the Animations**: Tulips sway, butterflies fly, hearts float
- **Enjoy the Details**: Notice the sparkles, blush, and gentle movements

## 🎨 Customization Ideas

Want to personalize it? Here are some easy changes you can make:

### Change the Message

Find this line in the HTML (around line 446):

```html
<h1>For Someone Special 💕</h1>
<p>Like tulips blooming in the garden of my heart</p>
```

Replace with your own message!

### Add More Tulips

Copy any tulip div block and adjust the positioning classes to add more flowers.

### Change Colors

Modify the color variables at the top of the CSS:

```css
--light-pink: #f3a69e;
--pink: #ff8081;
--purple: #b19cd9;
```

## 🎭 Animation Details

The scene includes these animations:

- **Tulip Swaying**: 3-3.5 second cycles with natural rotation
- **Head Bobbing**: Gentle up-and-down movement
- **Leaf Waving**: Realistic leaf flutter in the breeze
- **Petal Floating**: Subtle floating motion
- **Blush Pulsing**: Soft, rhythmic glowing effect
- **Sparkle Rotation**: Twinkling star effect on each flower
- **Heart Floating**: Hearts rise and fade into the sky
- **Butterfly Flight**: Complex figure-8 flight patterns
- **Grass Swaying**: Individual grass blades move independently
- **Star Twinkling**: Random twinkling patterns in night mode

## 🔧 Troubleshooting

**Animations not working?**

- Make sure you're using a modern browser
- Try refreshing the page
- Check that JavaScript is enabled

**Day/Night toggle not working?**

- Ensure the HTML file opened correctly
- Try a different browser
- Check browser console for errors (F12)
